# Задание 1

## Задача 7

### Текст задачи

Даны вектор V, дек D и список L. Каждый исходный контейнер содержит не менее двух элементов, количество элементов является четным. Поменять значения двух средних элементов каждого из исходных контейнеров. Использовать алгоритм swap (не путать его с одноименной функцией-членом контейнера).

### Алгоритм решения

Каждый из трёх контейнеров (вектор, дек, список) заполняется с помощью конструктора соответствующего контейнера, принимающего диапазон итераторов.

Для каждого контейнера отдельно находятся два средних элемента. Итератор устанавливается на начало контейнера и сдвигается на N/2 − 1 позиций, где N — размер контейнера; так он указывает на левый средний элемент. Второй итератор получается из первого сдвигом ещё на одну позицию и указывает на правый средний элемент. Значения, на которые указывают эти два итератора, меняются местами алгоритмом `std::swap`.

Поскольку итераторы списка не поддерживают произвольный доступ, сдвиг выполняется поэлементно для списка, для остальных контейнеров используется произвольный доступ с помощью итератора. После обмена элементы каждого контейнера выводятся в прямом порядке с помощью итераторов.

# Задание 4

## Задача 3

### Текст задачи

Дан набор вещественных чисел, содержащий не менее двух элементов. Вывести числа из исходного набора с четными порядковыми номерами (т. е. второе число, четвертое число и т. д.). Использовать алгоритм remove_copy_if.

### Алгоритм решения

Обработка выполняется без контейнеров: числа читаются из входного потока с помощью итераторов `istream_iterator<double>` (начальный итератор и итератор конца потока задают входной диапазон), а результат записывается через `ostream_iterator<double>` с пробелом в качестве разделителя.

Отбор выполняется алгоритмом `remove_copy_if`, который копирует в выходной поток все элементы, для которых условие ложно. Условие задаётся лямбда-выражением, захватывающим по ссылке счётчик прочитанных чисел: при каждом вызове оно проверяет, является ли текущее значение счётчика (нумерация с нуля) чётным, и увеличивает счётчик. Чётный индекс с нуля соответствует нечётному порядковому номеру, поэтому такие числа отбрасываются, а в вывод попадают числа со 2-м, 4-м и т. д. порядковыми номерами.

# Задание 5

## Задача 3

### Текст задачи

Дан список L. Удалить первый и последний нулевой элемент списка. Если нулевых элементов нет, то список не изменять, если нулевой элемент всего один, то удалить только его. Использовать два вызова алгоритма find и два вызова функции-члена erase.

Указание. Имеющуюся в классе list функцию-член remove в данном случае использовать нельзя, так как она удаляет все элементы с определенным значением. См. также указание к задаче 5.2.

### Алгоритм решения

Первый вызов алгоритма `find` выполняется по обычным итераторам от начала до конца списка и находит первый нулевой элемент. Если он найден, то удаляется функцией-членом `erase`.

Второй вызов `find` выполняется по обратным итераторам (`rbegin`, `rend`) и находит последний нулевой элемент списка. Если такой элемент найден, обратный итератор преобразуется в обычный выражением `(++r).base()`: функция `base` возвращает итератор на элемент, следующий за тем, на который указывает обратный итератор, поэтому обратный итератор предварительно сдвигается на одну позицию. Полученный итератор передаётся во второй вызов `erase`.

Так как поиск последнего нуля выполняется уже после удаления первого, при единственном нулевом элементе второй поиск ничего не находит и удаляется только один элемент; при отсутствии нулей список не изменяется.

### Текст задачи

Дан дек D с четным количеством элементов. Решить для него задачу 6.11. Поскольку операция вставки делает все итераторы дека недействительными, для решения задачи использовать вспомогательный дек D0. Инициализировать дек D0 первой половиной элементов дека D, после чего применить алгоритм replace_copy_if, используя дек D0 как источник, а дек D как приемник данных.

(Задача 6.11: Дан список L с четным количеством элементов. Скопировать в конец списка все элементы, расположенные в его первой половине, заменив при этом отрицательные элементы на нули и расположив скопированные элементы в обратном порядке. Использовать алгоритм replace_copy_if, итератор вставки и обратные итераторы, а также функцию advance.)

### Алгоритм решения

Итератор на середину дека D получается из итератора начала сдвигом на N/2 позиций с помощью функции `advance`. Вспомогательный дек D0 создаётся конструктором по диапазону от начала D до найденной середины, то есть содержит копию первой половины элементов.

Затем вызывается алгоритм `replace_copy_if`: источником служит дек D0, перебираемый обратными итераторами (`rbegin`, `rend`), что даёт обратный порядок копируемых элементов; приёмником — итератор вставки `back_inserter` для дека D, добавляющий элементы в его конец. Условие замены задаётся лямбда-выражением, проверяющим, что элемент отрицателен, а значение для замены — 0. Так как чтение идёт из отдельного дека D0, вставка в D не влияет на итераторы источника.

## Задача 9

### Текст задачи

Дан дек D. Решить для него задачу 7.7, используя один вызов алгоритма stable_sort с параметром — функциональным объектом.

(Задача 7.7: Дан список L. Перегруппировать элементы списка, расположив в нем вначале отрицательные, затем нулевые, а затем положительные элементы (порядок расположения элементов в каждой группе должен совпадать с исходным). Использовать два вызова алгоритма stable_partition.)

### Алгоритм решения

Для сравнения элементов используется функциональный объект, который каждому числу ставит в соответствие номер группы: 0 для отрицательных чисел, 1 для нуля и 2 для положительных. Операция сравнения считает один элемент меньше другого, если номер его группы меньше, то есть сравниваются не сами значения, а только их знаки.

Дек сортируется одним вызовом алгоритма `stable_sort` с этим функциональным объектом. В результате элементы упорядочиваются по группам: сначала отрицательные, затем нулевые, затем положительные. Элементы одной группы с точки зрения функционального объекта эквивалентны, а `stable_sort` сохраняет взаимный порядок эквивалентных элементов, поэтому внутри каждой группы остаётся исходный порядок.

## Задача 1

### Текст задачи

Дан список L. Получить вектор V вещественных чисел, содержащий значения среднего арифметического для всех пар соседних элементов исходного списка (количество элементов вектора V должно быть на 1 меньше количества элементов списка L). Например, для исходного списка 1, 3, 4, 6 полученный вектор должен содержать значения 2.0, 3.5, 5.0. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для вектора V.

### Алгоритм решения

Алгоритм `adjacent_difference` вызывается для всего списка L, а результат записывается в изначально пустой вектор V вещественных чисел через итератор вставки `back_inserter`. Вместо стандартной операции вычитания алгоритму передаётся функциональный объект, который для текущего и предыдущего элементов возвращает их полусумму, вычисленную в вещественной арифметике.

Алгоритм `adjacent_difference` записывает первым элементом результата копию первого элемента исходного диапазона, а начиная со второго — результаты применения функционального объекта к парам соседних элементов. Поэтому после его работы первый элемент вектора V, не являющийся средним арифметическим, удаляется функцией-членом `erase`. В итоге вектор содержит на один элемент меньше, чем список L.

# Задание 9

## Задача 2

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, …, VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, …, VN. Найти количество векторов VI, I = 1, …, N, в которых содержатся все элементы вектора V0 (с учетом их повторений). Использовать алгоритм includes, применяя его в цикле к двум мультимножествам (контейнерам типа multiset), одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1, …, N.

### Алгоритм решения

На основе вектора V0 создаётся мультимножество (контейнер `multiset`), которое хранит элементы в отсортированном виде с сохранением повторений.

Далее в цикле для каждого вектора VI создаётся своё мультимножество из его элементов. Алгоритм `includes` проверяет, входит ли мультимножество V0 в мультимножество VI. Поскольку оба контейнера отсортированы и хранят повторяющиеся значения, `includes` учитывает кратность элементов: значение, встречающееся в V0 k раз, должно встречаться в VI не менее k раз. Если проверка проходит успешно, счётчик подходящих векторов увеличивается. После обработки всех N векторов значение счётчика выводится как результат.

# Задание 10

## Задача 4

### Текст задачи

Дан вектор V, элементами которого являются английские слова, набранные заглавными буквами. Выполнить группировку элементов вектора V, используя в качестве ключа группировки последнюю букву элемента: в одну группу должны входить все элементы вектора V, оканчивающиеся одной и той же буквой (сгруппированные элементы должны располагаться в порядке, обратном порядку их расположения в исходном векторе). Представить результат группировки в виде мультиотображения M, ключами которого являются ключи группировки, т. е. последние буквы элементов вектора V, а значениями — элементы вектора, оканчивающиеся на соответствующую букву (таким образом, отображение M должно иметь тип multimap<char, string>). Вывести полученное отображение (для каждого элемента отображения M вначале выводить ключ, а затем связанный с ним элемент вектора V; ключи могут повторяться). Для перебора элементов контейнеров использовать цикл for по элементам контейнера.

### Алгоритм решения

Создаётся пустое мультиотображение `multimap<char, string>`. Элементы вектора V перебираются в обратном порядке с помощью обратных итераторов (`rbegin`, `rend`), и каждое слово добавляется в мультиотображение в паре с ключом — своей последней буквой, полученной функцией-членом строки `back`.

Мультиотображение автоматически упорядочивает элементы по ключам, то есть слова группируются по последней букве в алфавитном порядке букв. Элементы с одинаковым ключом располагаются в порядке их добавления, а так как вектор просматривался с конца, внутри каждой группы слова оказываются в порядке, обратном исходному. После этого мультиотображение перебирается от начала до конца, и для каждого элемента выводятся ключ и связанное с ним слово.
